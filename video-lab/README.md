# video-lab

Produção de reels FREMEX por código.

- `guia-de-estilo-reels_v0.1.md` — análise das referências e regras do formato.
- `render.js` — renderizador: composição HTML → MP4 (Playwright + FFmpeg).
- `piloto-01/` — primeiro piloto (Método CRIAR, 13 s).

Requisitos: Node.js, Playwright com Chromium e FFmpeg.
