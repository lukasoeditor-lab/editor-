## 1. Objetivo de aprendizagem

Escolher entre Claude Chat e Claude Code para uma tarefa usando a matriz de decisão FREMEX.

## 2. O que o aluno vai aprender

- As seis perguntas da matriz Chat × Code.
- O caminho mais comum de um job pelo Método CRIAR.
- Como evitar os dois erros mais frequentes: usar o Code para conversar e o Chat para produzir arquivos em série.

## 3. Roteiro de gravação

**[CÂMERA]**

Escolher a ferramenta errada é a forma mais rápida de perder tempo com IA. Tem gente pedindo para o chat "gerar 200 imagens redimensionadas", recebendo um texto de instruções e achando que a IA não funciona. E tem gente abrindo o Claude Code para pensar na ideia de uma campanha, quando uma conversa resolveria em cinco minutos.

Para não depender de intuição, a gente usa uma matriz com seis perguntas. Você responde na ordem, e a primeira resposta "sim" indica o caminho.

**[CORTE]**

**[GC]** Matriz Chat × Code

*Slide com a matriz, revelando uma pergunta por vez.*

**Um:** o resultado é uma ideia, um texto, uma análise ou uma decisão? Se sim, **Chat**.

**Dois:** você ainda precisa conversar e explorar antes de saber o que quer? **Chat**.

**Três:** o resultado são arquivos no seu computador, como uma página, um vídeo ou uma imagem gerada? **Code**.

**Quatro:** a tarefa mexe em muitos arquivos de uma vez, renomeando, convertendo ou organizando? **Code**.

**Cinco:** precisa rodar uma ferramenta, como renderizar um vídeo ou exportar um SVG? **Code**.

**Seis:** você vai repetir isso toda semana? **Code**, e vale transformar em um fluxo reutilizável.

**[CORTE]**

Vamos testar com tarefas da Nova Orla.

**[GC]** "Transformar o e-mail da cliente em briefing"

O resultado é um texto. Pergunta um: sim. **Chat**.

**[GC]** "Criar a vinheta animada da marca em vídeo"

O resultado é um arquivo de vídeo, e precisa rodar uma ferramenta de renderização. **Code**.

**[GC]** "Adaptar 40 fotos para o formato do Instagram"

Muitos arquivos de uma vez. **Code**.

**[GC]** "Escrever o roteiro do vídeo de 30 segundos"

Texto. **Chat**.

**[CORTE] [CÂMERA]**

Repara que, num job inteiro, você usa os dois. O caminho mais comum é este:

**[GC]** Chat → Compreender e Roteirizar · Code → Integrar · os dois → Aprimorar e Reaproveitar

Você começa no **Chat** para entender e planejar. Leva o plano para o **Code** para construir. E usa os dois para revisar e guardar o que funcionou.

Se você está na trilha Essencial, vai passar a maior parte do tempo nas duas primeiras etapas, no chat. E isso já muda muito o seu trabalho. Quando quiser dar o próximo passo, o Code estará esperando no módulo 03.

Na próxima aula: o que o Claude não faz. É uma das aulas mais importantes do curso.

Matriz Chat × Code.

## 8. Resumo final

- Seis perguntas decidem o modo. A primeira resposta "sim" vale.
- Texto, ideia e análise ficam no Chat. Arquivos, lotes e ferramentas ficam no Code.
- Um job completo usa os dois: Chat para pensar, Code para construir.
