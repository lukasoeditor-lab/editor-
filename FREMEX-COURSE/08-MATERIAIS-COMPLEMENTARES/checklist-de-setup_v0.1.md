# Checklist de setup — Método CRIAR

**Versão:** 0.1 · **Requisitos consultados em:** 11/11/2026 (code.claude.com/docs/en/setup)

## Trilha Essencial

- [ ] Navegador atualizado (Chrome, Edge, Firefox ou Safari)
- [ ] Internet estável
- [ ] Conta no Claude criada e com login feito
- [ ] Pasta `Metodo-CRIAR` criada no computador ou no Google Drive

## Trilha Completa — computador

- [ ] Sistema: Windows 10 versão 1809+ · macOS 13+ · Ubuntu 20.04+ · Debian 10+ · Alpine 3.19+
- [ ] Memória: 4 GB de RAM ou mais (8 GB ou mais recomendado para renderizar vídeo)
- [ ] Espaço livre em disco: ◆ valor recomendado a definir depois de medir os projetos
- [ ] Processador x64 ou ARM64

## Trilha Completa — contas

- [ ] Claude com plano Pro ou superior
- [ ] Conta no ElevenLabs (o plano gratuito serve para estudo; para uso comercial, plano pago)
- [ ] Conta Google (Drive)

## Trilha Completa — instalações (feitas no módulo 03 e no 05)

- [ ] Claude Code: `claude --version` mostra um número de versão
- [ ] `claude doctor` sem erros
- [ ] Windows: Git for Windows instalado (recomendado)
- [ ] Node.js ◆ (versão mínima a confirmar com Remotion e HyperFrames)
- [ ] FFmpeg ◆
- [ ] Inkscape

## Se algo falhar

1. Anote a mensagem de erro exatamente como aparece.
2. Confira a aula de instalação do seu sistema e a página oficial de solução de problemas do Claude Code.
3. Consulte o módulo de atualizações do curso.
